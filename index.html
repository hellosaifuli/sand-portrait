sand-portrait GitHub ↗
Canvas effect · no dependencies · under 6 KB gzipped

Any image, as sand.

Dots rise from a pile of sand into a portrait, then scatter from your cursor and spring back. Click to send a ripple. Drop in your own photo or type a word.

Hover · click · drop a photo
Use it

Two lines.

Give it a canvas and an image. Cut-out photos with a transparent background look best. It honours reduced motion and redraws when the canvas resizes.

<!-- script tag -->
<canvas id="me" style="width:400px;height:500px"></canvas>
<script src="https://cdn.jsdelivr.net/gh/hellosaifuli/sand-portrait@1/sand-portrait.js"></script>
<script>
  SandPortrait(document.getElementById('me'), { src: 'me.png' });
</script>

// or as a module
import SandPortrait from 'https://cdn.jsdelivr.net/gh/hellosaifuli/sand-portrait@1/sand-portrait.mjs';
const sand = SandPortrait(canvas, { src: 'me.png', on: 'dark', color: '#fff' });
sand.replay();
